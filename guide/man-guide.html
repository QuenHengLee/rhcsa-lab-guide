man 手冊速成

RHCSA 考試不能上網,但系統內建的 man 手冊可以查。指令選項、設定檔格式、甚至可直接照抄的範例,全都在裡面。與其死背,不如把「怎麼快速查到答案」練成反射動作——這頁教你這件事。

1man 是什麼、怎麼開

man = manual(手冊)。每個指令、設定檔、系統呼叫都有一份說明文件,man 名字 就能打開來讀。

$ man ls          # 讀 ls 指令的手冊
$ man passwd      # 讀 passwd 指令的手冊
$ man fstab       # 讀 /etc/fstab 設定檔的格式說明

打開後是一份可上下捲動的文件(用 less 顯示),按 q 離開。文件結構固定,認得幾個標題就能快速跳到要看的地方:

段落標題裡面有什麼
NAME一句話說明這是什麼
SYNOPSIS指令怎麼下、參數順序
DESCRIPTION詳細說明
OPTIONS每個選項(-R、-v…)的意義——查旗標看這裡
EXAMPLES可直接照抄的範例指令——考場救星,通常在最底部
SEE ALSO相關的其他手冊(附章節編號,見第 3 節)

2在 man 裡面移動:less 快捷鍵

man 用 less 這個閱讀器顯示,所以以下按鍵在任何 man 頁都通用。最該記的是 / 搜尋和 G 跳到底——這兩個讓你不用逐頁捲。

/ 字串 Enter往下搜尋關鍵字 — 例如 /EXAMPLES 直接跳到範例段;/-R 找 -R 選項
n / N跳到下一個 / 上一個搜尋結果
G跳到最底部 — EXAMPLES 通常在這;記法「大寫 G 力氣大,衝到底」
g跳到最頂端
Space / f往下翻一頁
b往上翻一頁
↑ ↓上下一行
q離開 man,回到指令列
大小寫有意義:G 到底、g 到頂;n 順著找、N 倒著找。搜尋跳過頭時,N 往回退一個結果即可。

3括號裡的數字:手冊章節

同一個名字可能在多個「章節」都有手冊(例如 crontab 既是指令、又是設定檔)。SEE ALSO 裡看到的 fstab(5)、semanage-port(8),括號數字就是章節編號。

1一般指令ls、grep、cp…
5設定檔格式fstab、sudoers、crontab
8系統管理指令useradd、semanage…
2/3程式函式寫程式才用
7雜項慣例regex、glob…

RHCSA 只要記 1、5、8。撞名時在 man 和名字中間加章節數字,指定要哪一份:

$ man crontab       # 開到 crontab(1):指令怎麼用
$ man 5 crontab     # 開到 crontab(5):五個時間欄位的格式 ← 排程題要看這個
$ man 5 fstab       # fstab 六欄位怎麼寫
第 5 章是考試最值錢的章節。所有「這個設定檔裡面該怎麼寫」的答案都在第 5 章:man 5 fstab、man 5 crontab、man 5 sudoers、man 5 chrony.conf…寫設定檔卡住,先想到它。

4忘記指令叫什麼?用關鍵字反查

知道「要做什麼」卻想不起「指令叫什麼」時,用 man -k(等同 apropos)拿關鍵字去搜所有手冊的簡介。

$ man -k passwd          # 所有和 passwd 有關的手冊
$ man -k time | grep 8    # 只看第 8 章(管理指令)裡和 time 有關的
$ man -k selinux         # 找出所有 SELinux 相關指令
若 man -k 回「nothing appropriate」,先跑一次 sudo mandb 重建索引再試——考試機偶爾需要這一步。

5考場黃金動線

把這條路徑練成反射:不會的指令 → man 開 → 搜到範例 → 照抄改路徑。整個過程不到十秒。

① 開
man 指令名
② 跳
按 G 到底,或 /EXAMPLES
③ 抄
照範例改成你的路徑/參數
④ 退
按 q 回指令列執行

實例——SELinux 檔案標籤題(sec-selinux-fix)忘了 semanage fcontext 語法:

$ man semanage-fcontext
  (按 G 跳到底,EXAMPLES 段就有這行可抄:)
  semanage fcontext -a -t httpd_sys_content_t "/web(/.*)?"
  (按 q 離開,把 /web 改成你的目錄 /lab-content 就是答案)
會查 man = 少背一半的東西。RHCSA 不考「你記不記得語法」,考「你做不做得出來」。語法忘了不扣分,查得到、做得對就給分——所以與其硬背 (/.*)? 這種細節,不如把「man → G → 照抄」練熟。

補充:很多服務有專屬的 SELinux 手冊,例如 man httpd_selinux、man nfs_selinux——裡面直接列出該服務所有相關的 boolean 和檔案標籤,SELinux 題卡住時是一座金礦。這些頁面由 selinux-policy-doc 套件提供,考試機通常已裝。
