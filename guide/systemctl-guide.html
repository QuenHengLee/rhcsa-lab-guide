systemctl 用法速查

systemctl 是管理 systemd「單元(unit)」的總指令——服務、timer、掛載點、開機目標都是 unit。RHCSA 幾乎每個服務題都在用它。這頁把常用的 systemctl <動作> <UNIT> 分類整理,並講清楚最容易搞混的 enable vs start。

0什麼是 unit

unit 是 systemd 管理的一個「東西」,用副檔名區分類型。服務名可以省略 .service:systemctl start httpd = systemctl start httpd.service。

副檔名是什麼例
.service服務(常駐程式)httpd.service、sshd.service
.timer定時觸發器labreport.timer
.target一組狀態(開機目標)multi-user.target
.mount掛載點由 fstab 產生
.socket監聽通訊端cockpit.socket

1當下控制:開/關/重啟

這些只影響「現在執行中的狀態」,重開機後不保證還在(那要靠第 2 節的 enable)。

指令作用
systemctl start UNIT立即啟動
systemctl stop UNIT立即停止
systemctl restart UNIT重啟(停了再開)
systemctl reload UNIT重讀設定但不中斷連線(僅部分服務支援)
systemctl reload-or-restart UNIT能 reload 就 reload,否則 restart

2開機persistence:enable/disable/mask

這些決定「重開機後要不要自動啟動」,以及能不能被啟動。RHCSA 服務題的分數大多在這裡。

指令作用
systemctl enable UNIT設定「開機時自動啟動」(但不會馬上啟動)
systemctl enable --now UNIT★ enable + 立即 start,一次到位(最常用)
systemctl disable UNIT取消開機自動啟動(不會停掉正在跑的)
systemctl disable --now UNITdisable + 立即 stop
systemctl mask UNIT遮蔽:連到 /dev/null,完全無法啟動(手動、被相依都不行)
systemctl unmask UNIT解除遮蔽
disable ≠ mask:disable 只是「不隨開機啟動」,仍可手動或被別的服務拉起;mask 是「上鎖,誰都啟動不了」。題目說「確保某服務絕對不會被啟動」→ 用 mask。

4查看狀態

指令作用
systemctl status UNIT完整狀態(執行中?最近日誌?)
systemctl is-active UNIT現在有沒有在跑(印 active/inactive)
systemctl is-enabled UNIT開機會不會自動啟動(印 enabled/disabled/masked)
systemctl is-failed UNIT是不是失敗狀態
systemctl cat UNIT看這個 unit 的設定檔內容
systemctl list-units --type=service列出目前載入的服務
systemctl list-unit-files列出所有 unit 及其 enable 狀態
systemctl list-timers列出所有 timer 與下次觸發時間
# systemctl is-enabled --quiet httpd && echo yes   # 腳本/評分常用

5系統層級(不接 UNIT 或接 target)

指令作用
systemctl daemon-reload改了 unit 檔或 fstab 後,叫 systemd 重讀設定
systemctl get-default查目前預設開機 target
systemctl set-default multi-user.target設定預設開機 target(文字模式)
systemctl isolate multi-user.target「立刻」切到某 target(不重開機)
systemctl reboot / poweroff重開機 / 關機
改了 unit 檔一定要 daemon-reload:你新增/編輯 /etc/systemd/system/xxx.service 後,systemd 手上還是舊的,必須 daemon-reload 讓它重讀,再 enable --now。timer 題、service 題都會用到。

6考題常見組合

# 服務要「現在跑 + 開機自動」:
# systemctl enable --now firewalld

# 某服務要「絕對不能被啟動」:
# systemctl mask --now httpd

# 改回文字模式開機:
# systemctl set-default multi-user.target

# 建好 timer 之後(先 daemon-reload,再 enable timer 而非 service):
# systemctl daemon-reload
# systemctl enable --now labreport.timer

# 驗證三連(對應 is-active / is-enabled / status):
# systemctl is-active httpd; systemctl is-enabled httpd
記一條黃金公式就夠應付八成服務題:systemctl enable --now <服務> —— 現在就啟動、開機也自動。剩下的特例:要鎖死用 mask、改開機模式用 set-default、改過 unit 檔先 daemon-reload。
