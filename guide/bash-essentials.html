Bash 腳本基礎

RHCSA 的腳本題不難:一個迴圈、一個條件判斷、比較字串或數字、看退出狀態。這頁把最常用的幾塊講清楚——退出狀態 $?、測試 [[ ]]、字串/數字比較、if...then...fi。

1退出狀態 $?:成功還是失敗

每個指令跑完都會留下一個「退出碼」:0 = 成功,非 0 = 失敗。用 echo $? 看上一個指令的退出碼——這是判斷、除錯的基礎。

$ ls /etc/passwd
/etc/passwd
$ echo $?
0          # 成功
$ ls /no/such/file
ls: cannot access ...
$ echo $?
2          # 非 0 = 失敗
$? 只反映「最後一個」指令。想用某指令的結果做判斷,要緊接著取 $?,或直接把它放進 if(見第 4 節)。腳本裡用 exit 0 / exit 2 自訂自己的退出碼。

2測試:[[ ... ]]

要「判斷條件成不成立」,用測試語法。它本身就是一個指令,成立→退出碼 0,不成立→退出碼 1。

$ [[ abc = abc ]]; echo $?
0          # 相等 → 成立 → 0
$ [[ abc = xyz ]]; echo $?
1          # 不相等 → 不成立 → 1

兩種寫法都可以,RHEL 上建議用 [[ ]](較新、較不易踩空白/萬用字元的雷):

寫法說明
[[ 條件 ]]bash 內建,較安全,支援 && ||、萬用字元比對。建議用這個
[ 條件 ]傳統 test 指令,POSIX 通用。中括號內外都要有空格
空格是必須的:[[ abc = abc ]] 對;[[abc=abc]] 錯(中括號和內容之間、等號兩邊都要空格)。這是最常見的語法錯誤。

3比較運算子:字串 vs 數字

字串和數字用不同的運算子——這是考點,別混用。

比較字串數字
相等= 或 ==-eq
不相等!=-ne
大於>(字典序)-gt
小於<(字典序)-lt
大於等於—-ge
小於等於—-le
是空字串-z 字串—
非空字串-n 字串—
# 字串:= 和 == 在 [[ ]] 裡等效
$ [[ "$USER" == root ]]; echo $?
# 字串不等於
$ [[ "$a" != "$b" ]]
# 數字:一定用 -eq / -lt 這類,不能用 = / <
$ [[ $# -eq 0 ]]          # 參數個數等於 0?
$ [[ $count -gt 10 ]]     # count 大於 10?
最常見的錯:拿 = 去比數字([[ $n = 5 ]] 其實是字串比較,"05" 就不等於 "5")、或拿 -eq 去比字串。口訣:字串用 =/==/!=,數字用 -eq/-ne/-lt/-gt。

4條件:if ... then ... fi

結構固定:if 後面接一個「指令或測試」,它退出碼 0 就執行 then 區塊。結尾一定是 fi(if 反過來拼)。

if [[ $# -eq 0 ]]; then
    echo "沒有參數"
elif [[ $# -eq 1 ]]; then
    echo "剛好一個參數"
else
    echo "多個參數"
fi

幾個要點:

  • then 可以跟 if 同一行(用 ; 隔開),或另起一行。
  • elif(else if)、else 可省略;最基本就是 if ... then ... fi。
  • if 後面不一定要 [[ ]]——任何指令都行,它判斷的是該指令的退出碼:
# 直接拿指令的成敗當條件(id 成功=使用者存在)
if id alice &>/dev/null; then
    echo "alice 存在"
else
    echo "alice 不存在"
fi
&>/dev/null 把指令的輸出丟掉,只取它的「成功/失敗」。這招在腳本判斷「某帳號/檔案存不存在」時很常用。

5組起來:一個完整小腳本

把上面全部用上——這就是 script-bash 練習題的縮影:

#!/bin/bash
# 沒給參數就印用法、以狀態 2 結束
if [[ $# -eq 0 ]]; then
    echo "usage: $0 USER [USER...]"
    exit 2
fi
# 逐一處理每個參數
for u in "$@"; do
    if id "$u" &>/dev/null; then
        echo "$u:$(id -u "$u")"
    else
        echo "$u:NOT FOUND"
    fi
done
exit 0
四個零件:$#(參數個數)、$@(所有參數)、$0(腳本名)、for ... in "$@"(逐一走訪)。"$@" 一定加雙引號,含空格的參數才不會被拆錯。寫完 chmod +x 腳本 才能執行。
